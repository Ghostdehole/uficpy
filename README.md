# uficpy

基于 [scrcpy](https://github.com/Genymobile/scrcpy) 的 Android 网页投屏，配套 [UFI-TOOLS](https://github.com/kanoqwq/UFI-TOOLS) 管理插件。把后端装到设备上，就可以用同一网络中的电脑或手机浏览器查看画面、操作设备。

后端运行在 **Android ARM64 / ARMv7 + Root** 设备上，管理插件负责安装、更新和配置，播放器由后端提供。设备上不需要安装 Node.js、FFmpeg，也不需要开启网络 ADB。

[下载最新版本](https://github.com/Ghostdehole/uficpy/releases/latest) · [安装步骤](#安装) · [国内下载源](#国内下载源) · [常见问题](#常见问题) · [功能对照](docs/FEATURES.md) · [更新记录](CHANGELOG.md)

## 功能

- **浏览器投屏**：H.264 视频，支持 WebCodecs、MSE 和 ManagedMediaSource，可重连、全屏、截图。
- **设备控制**：多指触控、鼠标滚轮、键盘、双向文字剪贴板，以及返回、桌面、多任务、屏幕开关、旋转、通知栏和应用启动。失焦或断线时释放输入。
- **应用与文件**：选择或拖入 APK，确认后安装；普通文件可直接上传到设备下载目录。
- **视频录制**：将收到的 H.264 原码流封装成 MP4 下载，不再次编码画面，录制文件暂不包含音轨。
- **可选声音**：Android 11 及以上可转发设备声音或麦克风，默认关闭，在播放器中手动启声。
- **画质设置**：可调分辨率、帧率、码率、编码器、裁剪和屏幕方向；播放器可单独调整缓存和解码偏好。
- **按需采集**：多个页面共用采集进程，默认无人观看 2 秒后停止采集，后台服务保持待命。
- **后端管理**：自动识别架构并下载对应安装包，支持更新、启停、自启、卸载、日志和设备诊断。
- **完整配置**：表单和 JSON 两种编辑方式，支持导入导出、只读模式、按键白名单、HTTPS 和备用下载源。

uficpy 是网页客户端，**尚未覆盖桌面 scrcpy 的全部功能**。当前视频使用 H.264，尚未实现 HEVC / AV1 / VP8 / VP9、相机投屏、虚拟显示和 UHID 键鼠手柄。具体支持范围见[功能对照](docs/FEATURES.md)。H.264 是有损编码，实际画质、帧率和延迟取决于设备编码器、浏览器与网络。

当前分支包含待审阅的 2.3.0 改动。合并并发布之前，下方 Releases 链接仍指向已有正式版；测试本分支时，需要使用同一构建产物中的管理插件和后端。新增功能仍需在实际 Android 设备上验证。

## 安装

### 安装前

- 设备运行 Android，架构为 ARM64 或 ARMv7，已经取得 Root。
- 已安装 UFI-TOOLS，能够登录管理页、加载插件并执行 Root 命令。
- 设备能访问 GitHub，或能访问下文的备用下载源。下载由设备发起，不是由打开管理页的电脑或手机代为下载。
- 设备上有支持 HTTPS 的 `curl`；插件也会尝试使用 UFI-TOOLS 内置的 `curl`。
- 用于观看的浏览器支持 H.264 解码。普通局域网 HTTP 使用 MSE / ManagedMediaSource；WebCodecs 需要安全上下文和浏览器支持。

### 1. 导入管理插件

打开 [Releases](https://github.com/Ghostdehole/uficpy/releases/latest)，下载附件中的 **`uficpy_plugin-v<版本号>.js`**，例如 `uficpy_plugin-v2.2.3.js`。

在 UFI-TOOLS 的插件管理中导入这个 JS 文件并启用，然后刷新管理页、登录，找到 **uficpy** 卡片。请只启用一份 uficpy 插件，更新时替换旧版。

这里安装的是管理插件，后端需要继续按下一步部署。普通用户无需下载源码，也无需手动上传 JAR。

### 2. 安装后端

展开 **管理与诊断 → 服务管理**，点击 **安装 / 更新**。

插件会识别设备架构，下载匹配的后端包，校验文件大小、SHA-256 和归档内容，再执行安装。安装完成后自动启动服务，安装目录为 `/data/uficpy`。

如果设备访问 GitHub 较慢或失败，先按[国内下载源](#国内下载源)设置发布源，再安装。需要确认架构时，可在 **管理与诊断 → 诊断 → 设备架构** 中查看，未安装后端也能使用。

安装期间保持管理页打开。如果提示请求中断或结果不明确，先点 **刷新状态** 并检查日志，确认是否已完成，不要连续重复安装。

### 3. 打开投屏

服务启动后，在 uficpy 卡片中展开投屏，或点击 **新窗口**。从插件打开时会自动携带访问令牌。

| 页面 | 默认地址示例 | 用途 |
| --- | --- | --- |
| UFI-TOOLS 管理页 | `http://192.168.0.1:2333/` | 安装插件、管理设备和后端 |
| uficpy 播放器 | `http://192.168.0.1:9528/` | 查看画面、触控和键盘操作 |

上面的 IP 只是示例，请使用自己的设备地址。`2333` 是 UFI-TOOLS 常见管理端口；播放器默认端口为 `9528`，可在插件中修改。直接输入播放器地址时，可能需要填写访问令牌，通常从插件的 **新窗口** 打开更方便。

浏览器提示 **点击播放** 时，点击一次即可继续。若管理页使用 HTTPS、播放器使用 HTTP，请用 **新窗口** 打开，或为播放器配置可信的 HTTPS 地址。

### 也可以通过插件商店安装

使用支持自定义插件源的 UFI-TOOLS，在商店中添加下面的源地址，再安装 uficpy：

```text
https://github.com/Ghostdehole/uficpy/releases/latest/download/repo.json
```

商店源要填写 `repo.json`，不是仓库首页，也不是后端的 `release.json`。商店安装后，同样需要执行上面的 **安装 / 更新**。源加载遇到跨域或代理问题时，见 [UFI-TOOLS 兼容性与排错](docs/UFI_COMPATIBILITY.md#插件商店源)。

## 国内下载源

项目提供一个备用后端下载源：

```text
https://download.doevt.top/uficpy
```

在 **管理与诊断 → 高级设置 → 发布源** 中填写：

| 设置 | 内容 |
| --- | --- |
| GitHub 仓库 | `Ghostdehole/uficpy` |
| 备用后端下载源 | `https://download.doevt.top/uficpy` |
| 下载顺序 | 国内网络可选 **备用源优先，失败后尝试 GitHub** |

点击 **保存发布源** 后，再执行 **安装 / 更新**。备用地址填写目录，不要在末尾加上 `/release.json`。

- **GitHub 优先**：先使用 GitHub，下载失败再尝试备用源。
- **备用源优先**：先使用备用源，下载失败再尝试 GitHub。
- **仅备用源**：清单和后端都从备用源读取，不访问 GitHub。

备用源由我手动同步，版本可能晚于 GitHub。选择备用源优先或仅备用源时，安装的是备用源已经同步的版本。设置只保存在当前浏览器，换浏览器或清除站点数据后需要重新填写。

这个设置只负责后端下载，不会修改 UFI-TOOLS 插件商店的下载地址。也可以使用自己信任的 HTTPS 静态服务器，目录结构和同步方法见 [备用下载源](docs/MIRROR.md)。

## 使用与画质设置

点击插件卡片中的 **参数**，可以选择预设或手动填写。默认使用平衡设置：

| 预设 | 最大长边 | 帧率上限 | 视频码率 |
| --- | --- | --- | --- |
| 节能 | 1280 | 30 FPS | 4 Mbps |
| 平衡 | 1920 | 60 FPS | 12 Mbps |
| 高画质 | 2560 | 60 FPS | 24 Mbps |
| 原生尺寸 | 不缩小 | 不设上限 | 40 Mbps |

这些数值是请求参数，不是实际性能保证。原生尺寸不会提高设备本身的分辨率；不设帧率上限也不代表设备一定能输出高帧率。建议先使用默认值，确认播放稳定后再调整。编码器可在 **管理与诊断 → 诊断 → 编码器 / 显示屏** 中查询。

播放器右上角的 **设置** 用来调整播放模式、解码偏好、目标缓冲和追赶阈值，这些偏好保存在当前浏览器。更小的缓存可能降低延迟，也更容易受网络抖动影响；“优先硬件”是给浏览器的偏好，并不保证使用硬件解码。

常用操作：

- 点击或触摸画面进行操作，支持多指触控和鼠标滚轮。
- 点击画面使其获得焦点后，可用方向键、回车、空格、Tab、退格等按键，`Esc` 对应返回。
- 底部的 **文字** 向设备粘贴文字；双向剪贴板位于 **工具 → 设备与剪贴板**，目标应用需要允许相应操作。**截图** 保存当前画面。
- 只想观看时，可在参数中开启只读模式，后端会拒绝控制输入。

完整配置位于 `/data/uficpy/config.json`，也可通过 **管理与诊断 → 高级设置 → 高级 JSON** 编辑、导入和导出。字段说明见 [配置文档](docs/CONFIGURATION.md)。导出的配置包含访问令牌，不要公开。

系统分辨率和 DPI 与投屏流尺寸是两项设置。修改系统显示参数后，需要单独点击 **应用系统显示**，会影响设备上的所有应用；还原时使用 **恢复显示**，仅清空输入框不会恢复。

## 安装 APK 与传文件

点击播放器顶部的 **工具 → 文件与应用**，可以选择本机文件，也可以把文件拖入工具窗口或投屏画面。手机浏览器使用文件选择器即可。

- **APK**：用途选择 **安装 APK**，选好文件后点击 **上传并安装**。选择或拖入文件本身不会开始安装。安装时允许更新同一个应用并保留应用数据；签名不一致、版本降级、系统版本不支持或空间不足时，会显示安装错误，不会为绕过错误自动卸载原应用。
- **普通文件**：用途选择 **上传文件**，选好文件后点击 **上传文件**，保存到 `/sdcard/Download/uficpy/`，完成后页面显示保存结果。已有同名文件时会提示重命名，不覆盖旧文件。可用设备上的文件管理器查看。
- 单个文件不能超过 **512 MiB**。上传需要设备有足够空间；只读模式不能上传或安装。

安装超时或连接中断时，系统可能仍在处理，先在设备上确认结果再操作，不要连续重试。上传用的 APK 临时文件会在本次请求结束时清理。

目前接收单个 `.apk`，不把 `.apks`、`.xapk` 或 `.apkm` 当成普通 APK 安装。多选 APK 也不等同于安装同一应用的拆分包。安装完成后，如需打开应用，可在 **工具 → 设备与剪贴板 → 启动应用（包名）** 中填写它的包名，例如 `org.mozilla.firefox`，再点击 **启动应用**。

## 剪贴板、声音与录制

**剪贴板是手动交换。** 在 **工具 → 设备与剪贴板** 中点击 **读取设备剪贴板**，文本会显示在页面中；点击 **复制到本机** 可复制，浏览器不允许时会选中文字供手动复制。反向传文字可用 **读取本机剪贴板** 或直接粘贴到文字框，再选择 **写入设备** 或 **写入并粘贴**。写入会改变 Android 剪贴板，粘贴是否成功还取决于当前应用。HTTP 页面及部分移动浏览器无法使用系统剪贴板接口，仍可通过文本框操作。

同一页还提供 **关闭设备屏幕 / 打开设备屏幕**、**旋转屏幕**、**通知栏**、**快捷设置** 和 **收起面板**。关闭的是物理屏幕，投屏仍继续；最后一个观看连接结束后会尝试恢复屏幕。请求已发送不代表 Android 或应用一定执行成功，应以设备实际状态为准。

**声音默认关闭。** 在管理插件的 **参数 → 设备声音** 中勾选 **采集设备音频**，选择音频来源并保存。重新连接播放器，在 **工具 → 录屏与声音** 中点击 **开启声音**。选择 **设备播放声音** 时转发设备输出，通常会停止设备本地扬声器播放；选择 **设备麦克风** 时采集的是 Android 设备周围的声音。播放器的 **静音** 和音量调节只改变当前浏览器播放，不会发送 Android 音量键。

音频需要 Android 11 或以上；Android 11 在开始采集时需要解锁屏幕。设备或固件不支持时会显示音频错误，视频和控制仍可继续使用。当前使用未压缩的 48 kHz 双声道 PCM，额外带宽约 **1.54 Mbps**，普通局域网 HTTP 也可播放。声音与画面使用独立缓冲，可能存在时间偏移，当前没有提供音画同步调节。

**录制直接保存视频码流。** 在 **工具 → 录屏与声音** 中点击 **开始录屏**，收到关键帧后开始记录。点击 **停止录屏** 后，再点 **下载录屏** 保存 `.mp4`。它不重新压缩画面，也不录入浏览器界面。当前录制 **没有音轨**，即使浏览器正在播放声音也是如此。

录制数据暂存在当前页面内存，单次上限为 **128 MiB 或 30 分钟**，先达到的限制生效。长时间或高码率录制会更快达到容量上限；请及时保存，关闭或刷新页面会丢失尚未下载的内容。达到限制、编码参数改变或连接中断时会结束当前片段，已有内容可下载；改变分辨率或画面方向后，可重新开始下一段。

## 更新、开机自启与卸载

**更新插件和更新后端是两步。** 先在 UFI-TOOLS 中更新管理插件，再点击 **安装 / 更新** 更新后端及其内置播放器。后端包已包含配套 scrcpy 核心，不要单独替换 `scrcpy-server.jar`。

| 操作 | 结果 |
| --- | --- |
| 安装 / 更新 | 保留现有配置、访问令牌、证书和系统显示恢复记录，原安装目录暂存为备份 |
| 全新安装 | 恢复默认配置并生成新令牌，仍保留证书和系统显示恢复记录 |
| 启动 / 停止 / 重启 | 控制后端服务，不会卸载文件 |
| 开机自启 | 切换自启设置，依赖 UFI-TOOLS 执行 `/sdcard/ufi_tools_boot.sh` |
| 卸载后端 | 删除后端、配置、自启项和 uficpy 旧备份，并尝试恢复已备份的系统显示参数 |

**启动、停止** 位于插件卡片主按钮区；安装、更新、重启、自启和卸载位于 **管理与诊断 → 服务管理**。安装成功不等于已经开启自启，需要重启设备后自动运行时，请单独设置 **开机自启**。

卸载后端后，管理插件仍会保留，方便重新安装。彻底移除时，先点击 **卸载后端**，完成后再到 UFI-TOOLS 中删除管理插件；仅删除 JS 插件不会停止或卸载后端。

## 常见问题

**下载失败，电脑却能打开 GitHub？**

下载实际发生在 Android 设备上。检查设备网络和时间，或设置国内备用源。备用源返回 404 时，通常是对应版本尚未同步；校验失败时不要跳过校验，先检查是否混用了不同版本的清单和安装包。

**提示“当前发布包仅支持 ARM64”？**

这是旧版架构检查的提示。2.2.3 起同时提供 ARM64 和 ARMv7 后端，需要更新管理插件；使用自建镜像时，也要同步包含对应架构的新清单和安装包。不要把 ARM64 包改名当作 ARMv7 包。

**管理页能打开，播放器打不开或没有画面？**

先确认后端处于运行状态，播放器端口没有被防火墙拦截。尝试从插件的 **新窗口** 打开；有播放按钮时点击播放。局域网 HTTP 可使用自动选择或兼容模式，不能强制要求 WebCodecs。仍无画面时，查看部署检查与日志，确认设备编码器是否能按当前参数启动。

**出现 JSON 解析错误或 “The string did not match the expected pattern.”？**

先查看 **管理与诊断 → 诊断 → 错误详情**。空响应、被截断的响应或地址处理都可能需要进一步排查，不能只凭提示断定原因。请记录报错操作、浏览器版本和失败请求，详见 [UFI-TOOLS 兼容性与排错](docs/UFI_COMPATIBILITY.md#json-或地址报错)。

**更新后界面没变化？**

确认更新的是后端，而不只是管理 JS；随后重新加载管理页和播放器，检查后端版本，并确保只启用一份管理插件。

其他问题可以提交到 [Issues](https://github.com/Ghostdehole/uficpy/issues)。请附上设备型号、Android / 固件版本、浏览器、插件和后端版本、复现步骤，以及 **检查部署 / 日志 / 错误详情** 的相关内容。提交前删除 token、Cookie、Authorization 和带访问令牌的地址。

## 访问安全与音量键

后端以 Root 运行，只从可信发布源安装，播放器默认用于可信局域网。HTTP 不加密画面和访问令牌，跨网络使用时请配置可信 HTTPS 或 VPN，不要直接把播放器端口开放到公网。更多说明见 [安全文档](docs/SECURITY.md)。

音量加减和静音功能仍然保留，但默认关闭。**部分 UFI 固件可能将音量键映射为恢复出厂设置，造成数据丢失。** 请先确认设备行为并备份，再决定是否开启：

1. 管理插件：**管理与诊断 → 高级设置 → 高级 JSON → 危险功能**，确认后允许音量键。
2. 播放器：**设置 → 高级控制 → 危险按键**，输入确认短语，解锁本次页面操作。

这些按钮发送真实 Android 按键，不是调节浏览器本地音量。只读模式仍会阻止控制输入。

## 开发

以下工具只用于开发和构建，普通用户按上面的插件安装步骤操作即可。CI 使用 Go 1.27、Node.js 24、Python 3、FFmpeg 和 Chrome。

```sh
npm ci
npx playwright install --with-deps chrome
sh scripts/test.sh
```

`sh build.sh` 会运行测试并生成 ARM64 和 ARMv7 发布包，输出到 `dist/`。更新 scrcpy 核心使用 `python3 scripts/sync_core.py --version latest`，版本和摘要记录在 `core-lock.json`；协议检查不通过时需要先完成适配。工作流与发布方式见 [构建与发布](docs/GITHUB_SETUP.md)。
