# 部署安全边界

- 后端拥有 Root 权限，发布仓库就是代码信任边界。只使用可信仓库。
- 通过 HTTPS 获取清单和资产，核对 SHA-256。它校验内容一致，不是独立于仓库账号的代码签名。
- 不关闭 TLS 证书校验，不执行 curl 输出；校验通过后才解压并执行安装。归档文件名、类型限制在发布包的已知集合。
- 每台设备随机 token，通过 WebSocket 子协议授权。HTTP 不加密 token 和画面，跨网络使用可信 HTTPS/VPN。
- 来源检查、控制白名单、包长度、队列、客户端上限都在后端执行；界面隐藏按钮不能代替权限。
- 音量键默认关闭，可从深层危险设置明确开启；开启后真实转发音量命令，不做静默屏蔽。部分固件可能因此恢复出厂。只读模式仍阻止全部控制。不自动开放网络 ADB，不修改 SELinux 策略。
- 安装/卸载只处理本项目目录、自启行；卸载不删除包含其他插件命令的整个启动脚本。
- Actions 固定核对过的提交，开发依赖有 lockfile/go.sum；PR 只读，发布只在默认分支执行。
- 若操作被强制中断留下 `/data/uficpy-operation.lock` 或 `/data/uficpy/.service-lock`，先确认没有操作正在运行，再删除对应锁目录。
