# 安全

后端以 Root 运行，插件发布源必须可信。默认不要将播放器端口暴露到公网。

## 访问与控制

每台设备生成独立 token，WebSocket 通过子协议授权。HTTP 不加密 token、画面、声音和上传文件，跨网络访问使用可信的 HTTPS 或 VPN。导出的配置包含 token，不要公开。

只读模式、来源检查、按键白名单和控制报文检查均由后端执行。文件上传、APK 安装和剪贴板操作同样受后端权限检查约束。隐藏按钮不会替代权限校验。

音量键默认关闭，需要手动开启并确认。**部分 UFI 固件可能在收到音量键时恢复出厂设置。** 开启后会发送真实 Android 按键；只读模式仍阻止全部控制。

项目不自动开放网络 ADB，也不修改 SELinux 策略。

## APK、文件和剪贴板

安装 APK 会运行第三方代码，只安装自己信任的文件。安装必须经过页面确认，不会因为把文件拖入页面就立即安装。安装使用 Android 包管理器，保留更新前的应用数据；签名或版本不匹配时停止，不自动卸载旧应用，也不自动授予所有运行时权限。安装超时或请求断开时，系统可能仍在安装，需要在设备上确认结果，不能把中断当作确定失败而重复安装。

普通文件保存在 `/sdcard/Download/uficpy/`，可能被设备上有相应存储权限的应用访问。不要用这个目录存放长期密钥或其他需要隔离的资料。文件上传有容量限制，但设备仍需预留足够的安装和存储空间。

剪贴板内容只在用户操作时交换，不自动持续同步。向设备发送的文本会写入 Android 剪贴板；从设备读取的文本会出现在当前页面。操作完成后留意页面中是否还保留了密码等敏感内容。

## 声音与录制

音频采集默认关闭。开启设备输出或设备麦克风前，确认正在被采集的内容可以共享给连接到此服务的人。浏览器静音只停止本机播放，不等于关闭设备采集；停止采集请关闭音频配置并重启，或停止后端。

视频录制由用户手动开始，文件暂存在当前浏览器，停止后下载到观看端。它不包含音轨。刷新、关闭页面或浏览器回收后台页面可能导致未保存内容丢失。

## 更新与卸载

下载使用 HTTPS，解压前校验 SHA-256、归档路径和文件类型。清单与运行包可以来自自建镜像，因此镜像服务器也属于信任范围。摘要用于检查内容一致性，不能防止发布账号或镜像服务器同时篡改清单与文件。

来源切换只重试下载，并锁定已选版本；清单、大小、SHA-256 或归档检查不通过时停止安装。Root 接口响应不明时不会继续切换或重复安装。

更新保留配置、token、显示恢复备份和 `certs/`。全新安装重置配置，但仍保留显示恢复备份和证书。私钥应放在 `certs/` 或安装目录之外，不要提交到仓库。

安装和卸载仅处理本项目目录及自启行，保留同一启动脚本中的其他插件命令。卸载会尝试恢复已备份的显示参数。

操作中断后若留下 `/data/uficpy-operation.lock` 或 `/data/uficpy/.service-lock`，先确认没有安装或服务操作正在运行，再清理相应锁目录。

## 构建依赖

Actions 固定到提交，Node 和 Go 依赖使用锁定文件。PR 仅有只读权限，发布任务只在默认分支运行。

设备剪贴板回复没有请求 ID。读取超时后会关闭并重建本代采集连接，而不是把可能迟到的内容交给下一个请求者。该恢复会影响当前观看页面，进行中的录屏将结束。
